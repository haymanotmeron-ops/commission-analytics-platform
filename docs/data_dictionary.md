# Data Dictionary

## raw_sales
| Column | Type | Description |
|---|---|---|
| sale_id | INT64 | Unique transaction identifier |
| sale_date | DATE | Date of sale |
| store_id | INT64 | Store identifier |
| rep_id | INT64 | Sales representative identifier |
| customer_id | INT64 | Customer identifier |
| revenue | NUMERIC | Revenue generated by the sale |
| commission_amount | NUMERIC | Commission paid for the sale |

## raw_reps
| Column | Type | Description |
|---|---|---|
| rep_id | INT64 | Unique representative identifier |
| rep_name | STRING | Representative name |
| hire_date | DATE | Representative hire date |
| commission_rate | NUMERIC | Commission rate applied to sales |

## raw_stores
| Column | Type | Description |
|---|---|---|
| store_id | INT64 | Unique store identifier |
| store_name | STRING | Store name |
| region | STRING | Geographic region |

## raw_customers
| Column | Type | Description |
|---|---|---|
| customer_id | INT64 | Unique customer identifier |
| segment | STRING | Customer segment |
